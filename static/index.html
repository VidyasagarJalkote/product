Deploying Local Database to Production via Dump Method

When you develop locally on your laptop, your data sits in your local PostgreSQL. Here is the standard DevOps 3-step workflow to export this database and restore it to a production server (AWS EC2, RDS, DigitalOcean, or Docker):

Step 1

Dump on Local Laptop

Run pg_dump to generate a complete SQL file of tables & records:

pg_dump -U postgres -h localhost -d devops_db -f devops_db_dump.sql
Step 2

Transfer to Remote Server

Copy the dump file securely to your production Linux server using SCP:

scp devops_db_dump.sql ubuntu@your-server-ip:/tmp/
Step 3

Restore on Production

Create the database on production and pipe the dump file using psql:

psql -U postgres -h localhost -d devops_db -f /tmp/devops_db_dump.sql
